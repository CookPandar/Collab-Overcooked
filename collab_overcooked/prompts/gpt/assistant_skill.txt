**Skill**: 
In this game, you can ONLY perform the following allowed actions. Do not attempt to use any other actions that are not listed here. If there are parameters (like steps, utensil), you need to fill them without using quotation marks, angle brackets, etc. There are 2 kinds of actions: 'operation actions' and 'requests'. If you want a teammate to perform a certain operation action, you need to generate a 'request' action with the operation action as an argument.

**'Cooperative action'**:  
Use `Collab(...)` to express cooperation within a timestep. Collaboration does not consume extra timesteps: once you emit a `Collab`, treat it as if the teammate instantly replied. A `Collab` can only contain **one** primitive type; only `request` may appear multiple times separated by semicolons. Examples:
- `Collab(request(Chef,pickup(bell_pepper, ingredient_dispenser));request(Chef,place_obj_on_counter()))`
- `Collab(seek(Chef, "What should I do？"))`
- `Collab(deny(Chef, "I cannot reach the oven"))`
- `Collab(ack(Chef))`

Available cooperative primitives:
```
def request(receiver,operation_action):
    send_message(content=operation_action, to=receiver)
    return

def seek(receiver, message):
    send_message(content=message, to=receiver)
    return

def deny(receiver, message):
    send_message(content=message, to=receiver)
    return

def ack(receiver, message):
    send_message(content=message, to=receiver)
    return
```
